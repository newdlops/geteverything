# 어드민 저장 공간 화면

기존 Django 관리 화면에 추가하는 운영 화면이다. 관리자는 DB와 크롤링 로그가 저장된 디스크의 남은 공간을 확인하고, 공간 부족과 측정 중단을 구분한다.

- 경로: `/admin/storage/`. 관리자 홈과 사이드바의 `서버 운영 → 저장 공간`에서 접근한다. 기존 직원 로그인 권한을 사용한다.
- 우선순위: 서버별 남은 공간 → 사용률·전체 용량 → DB 또는 로그 실제 사용량 → 측정 시각과 오류. DB와 로그는 다른 파일과 디스크를 공유한다는 설명을 표시한다.
- Django의 기본 글꼴, 색상 변수, `module` 패턴, 테두리와 버튼을 재사용한다. 본문은 기존 14px, 수치만 28px 안팎으로 강조한다. 여백은 8/16/24px을 사용하고 장식·그림자·새 아이콘 라이브러리를 추가하지 않는다.
- 넓은 화면에서는 서버별 영역을 두 열로 비교하고, 900px 미만에서는 한 열로 쌓는다. 최소 360px을 지원한다. 긴 호스트·경로는 줄바꿈한다. 키보드 초점을 명확히 보이고 버튼 높이는 44px 이상으로 한다.
- 정상·공간 부족·측정 대기·부분 오류·180초 이상 지연을 색과 문구로 함께 구분한다. 없는 수치를 0으로 표시하지 않는다. 실패 시 마지막 측정값과 시각을 보존한다.
- 서버에서 1분마다 가벼운 수집기를 실행한다. 웹 서버는 고정 명령으로 제한한 전용 SSH 키로 JSON 결과만 가져온다. 웹 요청은 읽기 전용 스냅샷을 읽으며 SSH·디렉터리 순회를 실행하지 않는다.
- `새로고침`은 최신 수집 결과를 다시 읽는다. 처리 중 중복 요청을 막고, 세션 만료·네트워크 오류를 표시한다. 60초 자동 갱신은 숨겨진 탭에서 쉬며 초점을 옮기지 않는다. 불필요한 애니메이션을 사용하지 않는다.
- 검증: 인증과 데이터 검증·측정 지연·수집 오류·용량 계산 테스트, 실제 서버 측정과 대조, 390×844·768×1024·1440×900 브라우저 검사, 새로고침·키보드·오류 상태 확인. 기존 크롤링과 DB 갱신이 계속되는지 적용 후 확인한다.

DB 크기는 [PostgreSQL의 용량 함수](https://www.postgresql.org/docs/16/functions-admin.html#FUNCTIONS-ADMIN-DBSIZE)로 측정하고 디스크 잔여량은 해당 서버 파일시스템에서 별도로 측정한다. 관리 화면은 [Django AdminSite 확장](https://docs.djangoproject.com/en/5.1/ref/contrib/admin/#adminsite-objects)을 사용한다.
# 로그 뷰어 추가 계약

2026-09-16 확장: 300줄 스냅샷 대신 마스킹된 시간 인덱스 이력을 조회한다. 출처·검색·심각도에 시작/종료 시각(KST)을 추가하며, 종료를 비우면 현재까지 조회한다. 최신순 200줄을 먼저 표시하고 스크롤 하단에서 이전 200줄을 이어 붙인다. 키보드·관찰자 미지원 환경용 `이전 로그 더 보기` 버튼도 제공한다. 실제 보관된 시간 범위와 최대 7일·64MiB 정책을 표시한다.

동일 시각 로그는 고유 ID로 구분하고 조회 시작 시점의 상한을 고정해 중복·누락을 방지한다. 조건 변경은 조회 목록과 커서를 초기화한다. 과거 페이지를 읽는 동안 자동 갱신은 멈추며 화면에는 최대 1,000줄만 유지한다. 이전 요청이 새 조건의 응답을 덮지 않아야 한다. 잘못된 날짜·역전 범위, 보관 범위 밖, 더 불러오는 중·실패·재시도·마지막 페이지를 구분한다. 웹 요청은 읽기 전용 로컬 SQLite만 조회한다.

검증에 KST 경계, 동일 시각 다수 행, 새 로그가 들어오는 동안 연속 페이지, 문자열의 SQL 와일드카드, 잘못된 커서, 1,000줄 이후 DOM 제한, 필터 변경 중 요청 취소, 모바일 날짜 입력 및 키보드 추가 로드를 포함한다. 기존 Django 시각 언어와 390/768/1440px 검증 기준을 유지한다.

- 사용자: 운영 슈퍼유저. 출처·시간 범위 선택 → 로그에서 오류 검색 → 스크롤로 이전 로그 확인.
- 기존 Django 관리자 색상 변수·글꼴·테두리·44px 버튼을 재사용한다. 모노스페이스는 로그 본문에만 사용한다.
- 위계: 보관 범위 안내와 저장 공간 링크, 출처/문자열/심각도/시간 필터, 갱신 상태, 로그 본문과 추가 조회 상태. 장식 카드나 신규 디자인 토큰을 추가하지 않는다.
- 390px부터 사용 가능. 필터는 좁은 화면에서 한 열, 본문은 줄바꿈하여 페이지 가로 넘침을 막는다. 긴 줄은 서버에서도 제한한다.
- 서버 수집과 화면 갱신을 구분한다. 약 1분 수집, 60초 화면 갱신은 선택 가능. 실제 보관 중인 이력을 시간 범위로 검색하며 화면의 200줄 페이지 제한과 보관 기간을 구분한다. 64MiB 제한으로 현재 약 5시간분만 보관되므로 7일 보관을 보장하는 문구를 쓰지 않는다.
- 권한 없음, 빈 로그, 검색 결과 없음, 수집 실패, 연결 실패 시 마지막 값 유지, 3분 지연, 요청 중, 초점/호버/비활성 상태를 처리한다. 로그 HTML은 항상 이스케이프한다.
- 기능 합격: 슈퍼유저만 접근, 출처 및 필터 동작, 갱신 취소/실패/재시도, 키보드 초점 유지, 출력·메모리·시간 상한, 민감값 마스킹.
- 시각 합격: 실제 Chromium에서 390×844, 768×1024, 1440×900의 기본·밀집·필터 결과를 확인한다. 밝은/어두운 테마와 긴 문자열을 확인한다. 전환 애니메이션은 추가하지 않는다.
