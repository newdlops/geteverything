# 상품 식별과 게시물 가격 이력

## 목적과 처리 순서

제목에서 식별 가능한 상품 정보를 추출해 영구 상품 ID에 게시물을 연결한다. 제목만으로 확인할 수 없는 옵션은 추정하지 않는다. 원본 게시물, 상품 연결, 가격 관측값, 학습 예제를 분리한다.

1. 상품·연결 작업·가격 관측·학습 예제 테이블과 변경 트리거를 추가한다.
2. 명확한 모델/규격은 결정적 규칙으로 연결하고, 나머지 유효 제목은 기존 로컬 LLM이 구조화한다. 상품명·브랜드·모델의 제목 근거와 숫자 사양을 검증한다.
3. 확인된 동일/다른 상품 예제로 CPU용 매칭 모델을 학습하고, 필드 정답이 확인된 예제로 Qwen LoRA 가중치를 미세학습한다. 자동 추론을 정답으로 재학습하지 않는다. 상품군을 분리한 검증에서 개선과 회귀 여부를 확인한 뒤 상품 추출 요청에만 반영한다.
4. 상품별 가격 이력 API와 어드민, 연결 수정·학습 피드백을 구현한다.
5. 분리·동시성·가격 보존·학습 검증 및 실제 브라우저 확인 후 운영에 적용하고 실제 모델 처리 결과를 확인한다.

## 상품과 가격의 경계

- 브랜드/제품군/모델/개별 용량/옵션이 상품 정체성이다. 묶음 수는 판매 구성으로 보관하고 같은 개별 규격끼리 단가를 비교한다.
- 355ml와 500ml, 1TB와 2TB, 제로와 일반, 다른 맛/색상/세대는 자동 병합하지 않는다. 사양이 누락된 제목을 구체적인 사양 상품에 합치지 않는다.
- UUID는 표시 이름 변경과 독립적이다. 유사한 제목만으로 기존 UUID를 강제 재사용하지 않는다.
- 가격 변경은 관측값을 추가한다. A→B→A도 세 관측으로 남기며 조회수 변경은 추가하지 않는다.
- 제목이 다른 상품으로 바뀌면 이전 가격을 새 상품으로 옮기지 않는다. 수동 연결을 바꿀 때는 현재 제목 세대의 연결만 수정한다.
- 기존 게시물은 저장된 가격 한 시점만 복원할 수 있다. 과거에 수집하지 않은 가격 변동을 만들어내지 않는다. 작성일과 가격 확인 시각을 함께 제공한다.
- 통화와 단가 기준을 섞어서 그래프를 그리지 않는다. 배송비/조건부 가격/수량 불명확 여부를 표시한다.

## 모델과 학습

- 외부 추론 API를 사용하지 않으며 기존 loopback llama.cpp 엔진을 공유한다. 크롤링과 DB 작업은 모델 응답을 기다리지 않는다.
- 신규 글 우선, 임대와 요청 revision 확인, 재시도 제한, 과거 글의 제한된 대기열을 사용한다.
- 운영자 확정/수정과 출처를 명시한 초기 검토 예제를 학습에 사용한다. 별도 검증 결과와 모델 버전을 보관한다. 모델의 자기 확신 점수를 정확도로 취급하지 않는다.
- 자원 보호는 유지하며 모델 작업 수요에 상품 식별 작업도 포함한다. 처리 건수·후보·학습 상태를 확인할 수 있게 한다.
- 사용자 확정: 묶음 수가 달라도 같은 개별 상품에 연결해 단가 비교. 외부 AI API 없이 서버 내부에서 실제 LLM LoRA 가중치 학습까지 수행한다. 학습과 추론의 자원 사용 시간은 분리한다.

## 어드민 화면 계약

기존 Django 어드민의 상품 목록 → 상품 상세/가격 이력 → 원본 게시물·연결 수정 흐름을 사용한다. UI UX Pro Max의 디자인 탐색에서 나온 소비자 상품 꾸미기 제안은 이 내부 도구에 맞지 않아 채택하지 않는다.

- 우선순위: 상품 이름/규격과 연결 상태, 기간·통화·단가 기준, 가격 그래프, 원본 게시물 표.
- 기존 시스템 글꼴, Django CSS 변수와 버튼·폼·표를 재사용한다. 숫자는 tabular-nums, 장식 카드/그라디언트/외부 글꼴은 추가하지 않는다.
- 8/16/24px 간격, 4px 이하 모서리, 기존 테두리 색. 최대 1280px, 한 열 본문, 높은 정보 밀도. 상태는 텍스트로도 표시한다.
- 390/768/1440px에서 확인한다. 컨트롤은 줄바꿈, 긴 제목은 본문에서 줄바꿈, 표만 영역 내부 가로 스크롤. 차트는 반응형 SVG와 동등한 데이터 표를 제공한다.
- 클릭/키보드 포커스/선택/처리 중/데이터 없음/검증 오류/권한 없음/저장 성공 상태를 제공한다. 움직임은 생략한다.
- 정상 상품 이력, 점 하나, 데이터 없음, 긴 제목, 혼합 통화, 수량 불명확, 연결 수정 후 이력 갱신을 기능과 시각으로 각각 확인한다.
- 상품 목록의 기존 처리 요약 아래에 LLM 미세학습 단계, 해당 단계의 진행률, 학습/검증 예제 수, 최근 기록 시각과 이번 가중치의 운영 반영 여부를 표시한다. 매칭 모델 학습과 구별하고 전처리를 가중치 학습 완료로 표현하지 않는다. 기존 검색 조건을 유지하는 새로고침 링크를 제공하며 대기·기록 없음·중단·검증 탈락·반영 완료·오래된 기록을 구별한다.
